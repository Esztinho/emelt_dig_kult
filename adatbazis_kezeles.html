Alapvető SQL Kérdések

Adatbázis-lekérdezési alapismeretek

  1. Mi az SQL?

    Az SQL (Structured Query Language) egy adatbázis-kezelő nyelve, amelyet az adatok lekérdezésére és manipulálására használnak.

  2. Mik a leggyakoribb SQL utasítások?

    A leggyakoribb SQL utasítások közé tartozik a SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER és DROP.

  3. Mi a különbség a WHERE és a HAVING között?

    A WHERE a sorok szűrésére szolgál a GROUP BY előtt, míg a HAVING a csoportosított adatok szűrésére használható a GROUP BY után.

  4. Mi az a PRIMARY KEY?

    A PRIMARY KEY egy vagy több oszlop, amely egyedileg azonosítja a rekordokat egy táblában, és nem tartalmazhat NULL értékeket.

  5. Mi az a subquery, és mikor használják?

    A subquery (al-lekérdezés) egy lekérdezés, amely egy másik lekérdezésen belül található. Gyakran használják összetett lekérdezésekhez, ahol egy lekérdezés eredményére van szükség a másikban.

  6. Hogyan használhatók az aggregáló függvények SQL-ben?

    Az aggregáló függvények, mint például a COUNT(), SUM(), AVG(), MAX(), és MIN(), az adatok csoportosítására és összesítésére szolgálnak. Ezeket a GROUP BY klauzulával együtt használják.

  7. Mi az a NULL érték, és hogyan kezelhető az SQL-ben?

    A NULL érték az adat hiányát jelzi. Az SQL-ben a NULL értékeket az IS NULL vagy IS NOT NULL operátorokkal kezeljük.

  8. Hogyan kérdeznéd le a legmagasabb árú terméket?

    SELECT * FROM products ORDER BY price DESC LIMIT 1;

További alapfogalmak

  • Adatbázis: Egy strukturált adatgyűjtemény, amelyben az adatok rendszerezett formában, táblákban vannak tárolva.
  • Adattábla: Az adattábla egy adatbázison belüli struktúra, amely sorokat (rekordokat) és oszlopokat (mezőket) tartalmaz.
  • Táblák közti kapcsolatok: Az adattáblák közötti kapcsolatok általában kulcsok segítségével jönnek létre:
    1. Egy-egy (One-to-One): Egy rekord csak egy másik rekordhoz kapcsolódik.
    2. Egy-több (One-to-Many): Egy rekord több rekordhoz kapcsolódik egy másik táblában.
    3. Több-több (Many-to-Many): Több rekord több rekordhoz kapcsolódik, amelyhez egy külön kapcsolótáblára van szükség.
  • Mező, rekord, adat: A mező az adattábla egy oszlopa, a rekord egy sora (egy entitás), az adat pedig az egyes mezők konkrét értéke.
  • Kulcsok típusai:
    • PRIMARY KEY: Egyedi azonosító minden rekordhoz, nem lehet NULL.
    • FOREIGN KEY: Másik tábla elsődleges kulcsára hivatkozik, kapcsolatot teremt.
    • UNIQUE: Biztosítja, hogy az értékek egyediek legyenek egy oszlopban.
  • Adattípusok: Szöveges (VARCHAR, TEXT), Szám (INT, FLOAT), Dátum (DATE, DATETIME) és Logikai (BOOLEAN).

Mintatétel: SQL utasítások és függvények

  1. Adatbázis létrehozása

    Az adatbázis létrehozásához a CREATE DATABASE utasítást használjuk.

    Szintaxis: CREATE DATABASE adatbazis_neve;
    Példa: CREATE DATABASE tanuloi_adatbazis;
  2. Táblák importálása és adatbeszúrás

    Az adatok beszúrására az INSERT INTO utasítást használjuk:

    Szintaxis: INSERT INTO tabla_neve (oszlopok) VALUES (értékek);
    Példa: INSERT INTO hallgatok (hallgato_id, nev) VALUES (1, 'Kiss Péter');

    Külső nagyméretű fájlok beolvasására adatbázis-kezelőtől függően a LOAD DATA INFILE parancs is alkalmazható.

  3. Táblák módosítása (Bővítés, Frissítés, Törlés)

    Bővítés (Oszlop hozzáadása):
    ALTER TABLE hallgatok ADD email VARCHAR(255);

    Adatok frissítése/módosítása:
    UPDATE hallgatok SET email = 'peter@example.com' WHERE hallgato_id = 1;

    Adatok törlése:
    DELETE FROM hallgatok WHERE hallgato_id = 1;

  4. Lekérdezések általános szintaxisa
    SELECT oszlopok FROM tabla WHERE feltétel GROUP BY oszlop HAVING feltétel ORDER BY oszlop LIMIT szám;
  5. Beépített SQL függvények (Dátum és Szövegkezelés)

    Időfüggvények: NOW(), CURRENT_DATE(), DATEDIFF()

    Szövegkezelés: CONCAT() (összefűzés), LENGTH() (hossz), UPPER() / LOWER() (kis/nagybetű).

SQL JOIN típusok

A JOIN műveletek célja, hogy két vagy több táblából adatokat kapcsoljanak össze közös mezők (kulcsok) alapján.

INNER JOIN: Csak azokat a rekordokat adja vissza, amelyeknél a kapcsolódó mezők értéke mindkét táblában megegyezik.
LEFT JOIN: Visszaadja a bal oldali tábla összes rekordját, a jobb oldali táblából pedig csak az egyezőeket. Ahol nincs egyezés, ott NULL jelenik meg.
RIGHT JOIN: A LEFT JOIN ellentéte; a jobb oldali tábla összes rekordját megtartja, és a bal oldali tábla nem egyező értékeit NULL-al tölti ki.
