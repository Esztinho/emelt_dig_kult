📘 Programozás

🧾 Adattárolás és változók

A programozás során az adatok átmeneti tárolására változókat használunk. A változó egy névvel ellátott memóriaterület, amelynek értéke a program futása során módosítható.

Alapvető adattípusok Pythonban:

  • int (Egész szám): Egész értékek tárolására, pl. kor = 18
  • float (Lebegőpontos szám): Tizedes törtek tárolására, pl. atlag = 4.55
  • str (Karakterlánc / Szöveg): Idézőjelek közé zárt szöveg, pl. nev = "Anna"
  • bool (Logikai érték): Két értéke lehet: True (Igaz) vagy False (Hamis).

Összetett adattárolás: A Lista (List)

Ha több, egymással összefüggő adatot szeretnénk egyetlen változóban tárolni, listát használunk. A lista elemei sorszámozva (indexelve) vannak, az indexelés mindig 0-val kezdődik. 

gyumolcsok = ["alma", "banán", "narancs"]
print(gyumolcsok[0])  # Kiírja: alma

Értékadás vs. Összehasonlítás

A vizsgán kritikus fontosságú a két operátor közötti különbség pontos ismerete:

  • Egyenlőségjel (=): Értékadás. A jobb oldalon lévő értéket menti el a bal oldali változóba. (Pl. x = 5)
  • Dupla egyenlőségjel (==): Összehasonlítás. Megvizsgálja, hogy a két oldal egyenlő-e, és logikai (True/False) értéket ad vissza. (Pl. if x == 5:)

🧭 Vezérlési szerkezetek

Alapértelmezetten a programok végrehajtása fentről lefelé, sorról sorra történik (szekvencia). Ezt a sorrendet tudjuk módosítani vezérlési szerkezetekkel.

1. Elágazások (Szelekció)

Feltételes végrehajtást tesznek lehetővé. Pythonban az if, elif (egyébként ha) és else (különben) kulcsszavakat használjuk. 

pontszam = 75
if pontszam >= 80:
    print("Kiváló")
elif pontszam >= 50:
    print("Megfelelt")
else:
    print("Elégtelen")

2. Ciklusok (Iteráció)

Műveletek automatikus ismétlésére szolgálnak, amíg egy adott feltétel teljesül.

  • Számlálós ciklus (for): Akkor használjuk, ha előre tudjuk az ismétlések számát, vagy végig akarunk menni egy lista elemein.
  • Feltételes ciklus (while): Addig ismétel, amíg a megadott feltétel igaz. Akkor hasznos, ha nem tudjuk előre, hányszor kell lefutnia (pl. adatbekérés ellenőrzése).
Fontos szabály (Blokkok és behúzás): A Python nyelvben nincsenek kapcsos zárójelek a kódblokkok jelölésére. A struktúrát, vagyis azt, hogy melyik utasítás tartozik a ciklushoz vagy az elágazáshoz, a kötelező behúzások (indentation - általában 4 szóköz) határozzák meg!

➕ Operátorok

A programban a változókon és értékeken különböző műveleteket végezhetünk az operátorok segítségével:

Aritmetikai (Matematikai) operátorok

  • +, -, *, / – Alapműveletek (összeadás, kivonás, szorzás, osztás).
  • % (Modulo): Az osztás maradékát adja vissza. Nagyon hasznos párosság vizsgálatakor (x % 2 == 0).
  • //: Egész osztás (lefelé kerekítve a legközelebbi egészig).

Összehasonlító és Logikai operátorok

Összehasonlításkor a >, <, >=, <= mellett a == (egyenlő) és != (nem egyenlő) jeleket használjuk.

Összetett feltételeket logikai operátorokkal köthetünk össze:

  • and: Csak akkor igaz, ha a kifejezés mindkét oldala igaz.
  • or: Igaz, ha leastwise az egyik oldal igaz.
  • not: Megfordítja a logikai értéket (igazból hamis lesz, és fordítva).

Speciális szöveges műveletek

A karakterláncokon is alkalmazható a plusz és a szorzás jel:

  • Összefűzés (+): Két szöveget fűz össze. Pl. "Jó" + "reggelt" eredménye "Jóreggelt".
  • Replikáció (*): Megismétli a szöveget. Pl. "ma"*3 eredménye "mamama".

🔧 Fontos beépített függvények

A Python számos előre megírt funkciót biztosít számunkra:

I/O és konverziós függvények

  • print(): Kiíratás a képernyőre.
  • input(): Adatbekérés a felhasználótól. Fontos: mindig szövegként (str) olvassa be az adatot!
  • int(), float(), str(): Típuskonverziós függvények. Szövegből számot, vagy számból szöveget formálnak.

Matematikai és Lista függvények

  • len(): Megadja egy lista elemeinek számát vagy egy szöveg karaktereinek hosszát.
  • min(), max(), sum(): Kiválasztja a legkisebb, legnagyobb elemet, vagy összegzi a lista elemeit.
  • append(): Új elemet fűz a lista végére. (Használata: lista.append(uj_elem))
  • random.randint(a, b): Véletlenszám-generálás a megadott `a` és `b` zárt intervallumban. Használatához a kód elején kötelező az import random parancs.

📋 Alapvető típusalgoritmusok

A típusalgoritmusok olyan általános programozási minták, amelyeket sűrűn alkalmazunk adathalmazok (listák) feldolgozása során.

1. Összegzés tétele

Egy lista elemeinek összeadására szolgál. Alapelve egy nullázott összeggyűjtő változó (`akku`), amihez ciklussal hozzáadjuk az elemeket.

szamok = [3, 5, 2, 8]
osszeg = 0
for szam in szamok:
    osszeg += szam
print("Összeg:", osszeg)

2. Megszámolás tétele

Megszámolja, hány darab egy bizonyos feltételnek megfelelő elem van a listában. Alapelve egy nullázott számláló, amit feltétel teljesülésekor növelünk.

darab = 0
for szam in szamok:
    if szam > 3:
        darab += 1
print("3-nál nagyobbak száma:", darab)

3. Szélsőérték (Maximum/Minimum) kiválasztás

Megkeresi a lista legnagyobb vagy legkisebb elemét. Alapelve, hogy a legelső elemet kikiáltjuk a legnagyobbnak, majd a többit hozzá hasonlítjuk.

legnagyobb = szamok[0]
for szam in szamok:
    if szam > legnagyobb:
        legnagyobb = szam
print("A legnagyobb szám:", legnagyobb)
További tételek: Az Eldöntés tételével azt vizsgáljuk meg, hogy van-e legalább egy feltételnek megfelelő elem a listában (pl. a `break` kulcsszó használatával, ha megtaláltuk), míg a Keresés során az elem helyét (indexét) is meghatározzuk.

📈 Emelt szintű témakörök (Haladóknak)

Az emelt szintű érettségi során az alábbi struktúrák ismerete is szükséges:

  • Kétdimenziós tömbök (Mátrixok): Listák listája, ahol az adatokat sorokba és oszlopokba rendezve tároljuk. Elérésükhöz egymásba ágyazott ciklusokat alkalmazunk.
  • Szótárak (Dictionary): Kulcs-érték párok tárolására alkalmas összetett adattípus (kulcs: ertek). Nem indexekkel, hanem egyedi kulcsszavakkal hivatkozunk az elemekre.
  • Fájlkezelés (I/O): Adatok beolvasása külső szöveges állományból (pl. `.txt`, `.csv`), vagy az eredmények elmentése merevlemezre a biztonságos with open() szerkezet használatával.
  • Saját függvények (def): Kódunk modularizálása, újrahasznosítható egyedi logikai blokkok létrehozása paraméterek és visszatérési értékek (return) segítségével.
