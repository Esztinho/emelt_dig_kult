Adattárolás és változók

1. Változók fogalma

Változók tárolják az adatokat. Pythonban nem kell előre deklarálni a változók típusát.

2. Adattípusok

Számok, szöveg, logikai értékek, lista stb.

Adattípusok röviden

  • int – egész számok, pl. 10, -5, 0
  • float – valós számok, tizedes törttel, pl. 3.14, -0.5
  • str – szöveg, karakterlánc, pl. "Hello", 'Világ'
  • bool – logikai értékek: True vagy False
  • list – elemek sorozata, pl. [1, 2, 3], [“a”, “b”, “c”]
  • dict – kulcs-érték párok, pl. {"név": "Anna", "kor": 16}
    (fájlbeolvasás után adatok eltárolására is használhatjuk a szótárakat)
  • tuple – nem megváltoztatható (immutábilis) elemek sorozata, pl. (1, 2, 3)
  • set – egyedi elemek halmaza, sorrend nem számít, pl. {1, 2, 3}
Példa Pythonban:
szam = 10
szoveg = "Hello, világ!"

Megjegyzés: Az adatok tárolása minden program feladat első lépése, fontos ezt jól átlátni.

3. Adattárolás két fajtája

Bekért adatokat és a számított adatokat is tároljuk.

4. Egyenlőségjel működése

Az egyenlőségjel (=) értékadást jelent: a jobb oldali értéket a bal oldali változó kapja meg. Ha feltételes vizsgálatot szeretnénk, dupla egyenlőségjelet (==) kell használunk, ami összehasonlítja a két értéket.

Példa Pythonban:


# Értékadás
szam = 10
szoveg = "Hello, világ!"

# Összehasonlítás
if szam == 10:
    print("A szám 10")

5. Lista

Lista fogalma: elemek sorozata, amelyek módosíthatók. Indexeléssel érhetjük el az egyes elemeket(ami 0-tól indul!), és különféle műveletek végezhetünk rajtuk.

1.) Deklarálás és indexelés

Lista létrehozása és elemek elérése indexekkel:


lista = [1, 2, 3, 4, 5]
elso_elem = lista[0]  # az első elem
utolso_elem = lista[-1]  # az utolsó elem

2.) Módosítás

Lista elemek módosítása, hozzáadása és eltávolítása:


# Elem módosítása
lista[0] = 10

# Elem hozzáadása a végéhez
lista.append(6)

# Elem eltávolítása érték alapján
lista.remove(3)

# Elem eltávolítása index alapján
del lista[2]

3.) Lista műveletek beépített függvényekkel

A Python listáira számos beépített függvény alkalmazható: len(), sum(), min(), max(), sorted() stb.

Példa Pythonban:


lista = [10, 3, 7, 2, 5]

# Lista hossza
print(len(lista))  # 5

# Elemek összege
print(sum(lista))  # 27

# Legkisebb elem
print(min(lista))  # 2

# Legnagyobb elem
print(max(lista))  # 10

# Lista rendezése (érdemes új listát létrehozni, és nem az eredetit módosítani!)
rendezett_lista = sorted(lista)
print(rendezett_lista)  # [2, 3, 5, 7, 10]

# Eredeti lista nem változik
print(lista)  # [10, 3, 7, 2, 5]

Ingyen pontok az Első feladatoknál: Elemek száma, első és utolsó adat

Az érettségi feladatsor 2. vagy 3. feladata szinte mindig az, hogy határozzuk meg, hány adatsor (pl. felajánlás, mérés, dolgozó) található a beolvasott állományban, illetve írjuk ki az első vagy az utolsó elemet.

A len() függvény

A len() (length = hossz) függvény megadja, hogy egy lista hány elemet tartalmaz.

# Tegyük fel, hogy az 'adatok' lista tartalmazza a beolvasott sorokat
sorok_szama = len(adatok)
print(f"2. feladat: A felajánlások száma: {sorok_szama}")

Első és utolsó elem kiírása

# Első elem (0. index)
print(f"Az első rögzített adat: {adatok[0]}")

# Utolsó elem (-1. index)
print(f"Az utolsó rögzített adat: {adatok[-1]}")
input() függvény

Az input() függvény lehetővé teszi, hogy a felhasználó adatot adjon meg a program futása közben. A függvény alapértelmezés szerint szöveget (string) kér be, és ezt az értéket adja vissza.

Alapvető használat


valasz = input("Írj be valamit: ")
print("A te válaszod:", valasz)

Mi történik?

  • A program megjeleníti a kérdést a felhasználónak.
  • A futás megáll, amíg a felhasználó be nem ír egy értéket.
  • Enter lenyomása után a program folytatódik.
  • A beírt adat a változóban tárolódik.

Típuskonvertálás

Mivel az input() mindig szöveget ad vissza, számokkal való műveletek előtt át kell alakítani a megfelelő adattípussá. 


szam = int(input("Írj be egy számot: ")) # rögtön át is alakítjuk egész számmá

print("A szám duplája:", szam * 2)

Gyakori konvertálások

  • int() → egész szám
  • float() → lebegőpontos szám
  • str() → szöveg

Összegzés

  • Felhasználói adatbevitel a program futása közben
  • Alapértelmezés szerint string típust ad vissza
  • Szükség esetén könnyen konvertálható más típusokra

Bejárás: For ciklus és egymásba ágyazott ciklusok

Ha a listánk összes elemét meg akarjuk vizsgálni, for ciklust használunk!!

Egyszerű For ciklus

Végigmegyünk a lista összes elemén, és mindegyikkel csinálunk valamit.

nevek = ["Anna", "Béla", "Cecil"]
for nev in nevek:
    print(nev)

Egymásba ágyazott For ciklus

Ilyenkor egy cikluson belül indítunk egy másikat. Ezt leggyakrabban mátrixok (kétdimenziós listák, pl. táblázatok, képpontok) feldolgozásakor, vagy egy listában lévő szavak betűire bontásakor használjuk. 

haromszogek = [[3, 2, 4], [4, 5, 7], [10, 4, 7]]  # adott 3 db háromszög és azok oldalhosszúságai
for haromszog in haromszogek:          # Külső ciklus: végigmegy a haromszogek listán
    print(f"Jelenlegi háromszög: {haromszog}")
    for oldalhossz in haromszog:        # Belső ciklus: végigmegy az adott haromszog oldalainak hosszán
        print(f" - Oldalhossz: {oldalhossz}")

Kimenet:


Jelenlegi háromszög: [3, 2, 4]
 - Oldalhossz: 3
 - Oldalhossz: 2
 - Oldalhossz: 4

Jelenlegi háromszög: [4, 5, 7]
 - Oldalhossz: 4
 - Oldalhossz: 5
 - Oldalhossz: 7

Jelenlegi háromszög: [10, 4, 7]
 - Oldalhossz: 10
 - Oldalhossz: 4
 - Oldalhossz: 7

For ciklus részletesen

A for ciklus egy iteratív vezérlési szerkezet, amely lehetővé teszi, hogy egy műveletet többször végrehajtsunk egy iterálható objektum (például lista, sztring vagy tartomány) minden elemén. Pythonban egyszerű és gyakran használt eszköz adatok feldolgozására.

Hogyan működik?

A for ciklus sorban végighalad az iterálható objektum elemein, és az aktuális elemet egy változóban tárolja. Minden iteráció során végrehajtja a ciklus belsejében található utasításokat.

Szintaxis


for valtozo in iteralhato_objektum:
    # végrehajtandó műveletek

A ciklus részei

  • for: a ciklus kezdete
  • változó: az aktuális elem értékét tárolja
  • in: megadja, mit járunk be
  • iterálható objektum: lista, sztring, szótár stb.

Egyszerű példa – lista bejárása


nevek = ["Anna", "Béla", "Cili"]

for nev in nevek:
    print(f"Üdvözöllek, {nev}!")

Mi történik?

  • A lista elemei egymás után a nev változóba kerülnek.
  • Minden elemnél lefut a print utasítás.

Iterálható objektumok

1. Lista


szamok = [1, 2, 3, 4, 5]

for szam in szamok:
    print(szam)

2. Sztring


szoveg = "Python"

for karakter in szoveg:
    print(karakter)

3. range() függvény


for szam in range(1, 6):  # 1-től 5-ig
    print(szam)

4. Szótár


adatok = {"nev": "Anna", "kor": 25}

for kulcs in adatok:
    print(kulcs, ":", adatok[kulcs])

Miért hasznos?

  • Egyszerű és tiszta: nem kell manuális számláló
  • Sokoldalú: minden iterálható objektumon működik
  • Automatizál: ismétlődő feladatokat kezel
  • Alapja az algoritmusoknak: keresés, számlálás, összegzés
Alap algoritmusok

Az érettségi programozási feladatok szinte mindig tartalmaznak alap algoritmusokat. Ezek biztos ismerete kulcsfontosságú.

1. Összegzés


#Feladat: Mennyi az 5-nél nagyobb számok összege?

szamok = [3, 5, 7, 12]
osszeg = 0

for szam in szamok:
    if szam > 5:
        osszeg += szam

print(osszeg) #19

Megjegyzés: Az összegzés során egy lista vagy adatsor elemeit adjuk össze, általában csak egy bizonyos feltételnek eleget tevő tagokat.

2. Megszámlálás


szamok = [5, 12, 7, 20]
db = 0

for szam in szamok:
    if szam > 10:
        db += 1

print(db)

3. Maximumkeresés


szamok = [3, 9, 4, 7]
legnagyobb = szamok[0]

for szam in szamok:
    if szam > legnagyobb:
        legnagyobb = szam

print(legnagyobb)

Felmerülhet a kérdés: Miért nem használhatjuk a max() függvényt?

Röviden: Érettségi feladatoknál nemcsak egyetlen értéket, hanem a hozzá tartozó adatokat is meg kell keresni.

  • Bonyolultabb adatszerkezetek: Gyakran listákban szótárak vagy több adatot tartalmazó sorok szerepelnek, nem csak egyszerű számok.
  • Több adat párhuzamos kezelése: Általában nemcsak a legnagyobb értéket keressük, hanem például a hozzá tartozó nevet vagy azonosítót is.
  • Átlátható algoritmus: A ciklus lépésről lépésre mutatja meg a működést, ezért könnyebben érthető.

Megjegyzés: Bár lambda és max() használatával is megoldható lenne, az érettségin általában a legegyszerűbben követhető, diákbarát megoldásokat várják el.

4. Minimumkeresés


szamok = [3, 9, 4, 7]
minimum = szamok[0]

for szam in szamok:
    if szam < minimum:
        minimum = szam

print(minimum)

5. Eldöntés

Itt csak azt nézzük, hogy van-e legalább egy megfelelő elem a listában. Az teljesen mindegy, hogy melyik az.


szamok = [2, 4, 6, 7]
van = False

for szam in szamok:
  if szam % 2 != 0:
      van = True

print(van)

6. Kiválasztás

Itt megkeressük az első megfelelő elemet, és általában el is mentjük vagy kiírjuk.


szamok = [3, 5, 8, 9]
legelso_paros = 0
for szam in szamok:
    if szam % 2 == 0:
        legelso_paros = szam
        break

✔️ Mikor kell a break?

👉 amikor már megtaláltuk az első megfelelő elemet, és nem akarjuk tovább futtatni a ciklust, mert nincs rá szükség vagy a feladat kifejezetten az első ilyen előfordulást keresi!

✔️ Egyszerű szabály (érettségire)

Ha az első megfelelőt keresed → kiválasztás → break.
Ha csak azt nézed, hogy van-e ilyen elem→ eldöntés → nem kötelező break.
Ha mind kell → megszámlálás vagy kiválogatás → nincs break.

Fájlbeolvasás és szótár használata

A fájl beolvasása és feldolgozása Pythonban alapvető feladat a gyakorlati érettségin. A szótárak segítségével az adatok kezelése sokkal átláthatóbbá válik, így később nem kell indexekkel bajlódni.

Fájl megnyitása és sorokra bontás


file = open("taborok.txt", "r", encoding="utf-8").read().splitlines()

# .read() → Az egész fájlt egy szövegként olvassa be
# .splitlines() → Sortörések mentén listára bontja
# Minden sor egy-egy listaelem lesz

Lista létrehozása a feldolgozott adatoknak

A fájl sorait szótárakba rendezzük, így a kód érthetőbb és könnyebben kezelhető lesz. 


taborok = []

for line in file:
    line = line.split("\t")  # tabulátor mentén daraboljuk

    tabor = {}
    tabor["kezdo_honap"] = line[0]
    tabor["kezdo_nap"] = line[1]
    tabor["reszvevok"] = line[2]
    tabor["tema"] = line[3]

    taborok.append(tabor)

print(taborok)

Így a taborok lista minden eleme egy szótár, amely tartalmazza a tábor adatait.

Fontos: az első sor külön kezelése!!

A fájl első sora gyakran valamilyen összesítő adatot tartalmaz (például egy darabszámot).

Mivel a beolvasott adatok listában vannak tárolva, az első elem indexe 0. Amennyiben számként szeretnénk használni az értéket, szükséges az int() típusátalakítás. 


agyasok_szama = int(file[0])

A további sorok feldolgozása

A második sortól kezdődnek a tényleges adatok. Ezeket egy ciklus segítségével dolgozzuk fel. 


for sor in file[1:]:
      #folytatás ugyanúgy a fentiek szerint

Magyarázat:

  • A file[1:] a lista második elemétől a végéig tartó rész.
  • Az első sort így kihagyjuk a feldolgozásból.
  • A ciklus minden egyes adatsort külön kezel.

Összegzés

  • Érthetőbb kód: kulcsok használata indexek helyett
  • Egyszerű hozzáférés: az adatok nevekkel érhetők el
  • Rugalmasabb: könnyebb később módosítani
  • Összetett adatok kezelése: listák és szótárak kombinálása
Keresés algoritmus

Gyakori feladat egy adott értékhez tartozó adatoknak a megkeresése. A legegyszerűbb módszer a lineáris keresés, amikor sorban végignézzük az elemeket, amíg meg nem találjuk a keresett adatot.

A keresés lépései

  • Bejárjuk a lista elemeit
  • Összehasonlítjuk a keresett értékkel
  • Találat esetén kiírjuk az eredményt

Példa: Tábor keresése téma alapján

A felhasználótól bekérjük egy tábor témáját, majd megkeressük, hogy mikor kezdődik az adott tábor.

Továbbá feladat az is, hogy ha nincs ilyen témájú tábor, amilyet a user megadott, akkor írjunk ki neki egy tájékoztató üzenetet!


# Feltételezzük, hogy a taborok lista már létezik (és szótárakat tartalmaz)

keresett_tema = input("Add meg a tábor témáját: ")

talalat = False

for tabor in taborok:
    if tabor["tema"] == keresett_tema:
        print("A tábor kezdete:",
              tabor["kezdo_honap"], ".", tabor["kezdo_nap"])
        talalat = True

if talalat == False:  #vagy írhatom így is: if not talalat:
    print("Nincs ilyen témájú tábor.")

Miért hasznos?

A keresés algoritmus egyik legfontosabb szerepe, hogy meg tudjuk állapítani, létezik-e a feltételeknek megfelelő adat az adathalmazban. Ebben az esetben azt vizsgáljuk, hogy van-e legalább egy olyan tábor, amelynek a témája megegyezik a felhasználó által megadottal.

A talalat változó segítségével nyomon követjük, hogy a ciklus során találtunk-e megfelelő elemet. Ha igen, akkor az értéke True-ra változik, ha pedig egyetlen egyezés sincs, akkor False marad.

Ez a módszer általánosan alkalmazható minden olyan feladatban, ahol egy listában vagy adatsorban szeretnénk megkeresni, hogy létezik-e egy adott tulajdonságú elem.

Függvények

Fogalma

A függvény egy olyan kódrészlet, amely [bemenet(ek)] alapján kiszámol valamit, majd az eredményt visszaadja a return segítségével.

Létrehozás és tulajdonságok

  • A függvény létrehozása a def kulcsszóval kezdődik, majd ezt követi a függvény neve.
  • Ezután kerek zárójelek között kell megadni a függvény bemeneteit (a bemenetek száma akár 0 is lehet).
  • A bezáró zárójelet kettőspont (:) követi.
  • Ezután behúzással kezdődik a függvényhez tartozó kód.
  • A függvényben a return paranccsal lehet visszaadni egy kimeneti értéket.

Általános szintaxis


def fuggveny_neve(egyik_bemenet, masik_bemenet):
    # tetszőleges műveletek
    # számold ki a visszatérési értéket
    return visszateresi_ertek

Az alábbi példák segítenek megérteni a függvények működését:

1. Szám négyzetének kiszámítása

Ez a függvény visszaadja a bemeneti szám négyzetét.


def negyzet(szam):
    return szam * szam


eredmeny = negyzet(4)
print(eredmeny)

Ebben az esetben:

  • A függvény megkapja a 4-et
  • Kiszámolja: 4 * 4
  • Visszaadja: 16

2. Páratlan szám ellenőrzése

Ez a függvény megmondja, hogy egy szám páratlan-e.


def paratlan(szam):
    return szam % 2 == 1

print(paratlan(7))  # True
print(paratlan(8))  # False

3. Két szám összege


def osszead(a, b):
    return a + b

Ez a függvény visszaadja a paraméterként megadott két szám összegét.


eredmeny = osszead(3, 5)
print(eredmeny)

Mi az a return?

A return kulcsszóval a függvény visszaad egy értéket. Ez az érték a függvény meghívásának helyére kerül vissza.

Hogyan működik a meghívás?


eredmeny = osszead(3, 5)
print(eredmeny)

Lépések:

  • A függvényt meghívjuk: osszead(3, 5)
  • A paraméterek értéket kapnak: a = 3, b = 5
  • A függvény kiszámolja: a + b
  • A return visszaadja az eredményt (8)
  • Az eredményt eltároljuk az eredmeny változóban

Fontos megérteni

A paraméterek (pl. a, b) csak a függvényen belül léteznek, és a függvény ezekkel az értékekkel dolgozik.

A return után a függvény azonnal befejeződik, és visszaadja az eredményt.

Összefoglalás

  • A függvény bemenetet kap (paraméterek)
  • Elvégez egy műveletet
  • A return segítségével visszaad egy értéket
  • Az eredményt eltárolhatjuk egy változóban

Tippek a függvényekhez

  • Legyen egyértelmű a név: A függvény neve mindig tükrözze, mit csinál (pl. paratlan, lista_osszeg).
  • Csak egy feladatot végezzen: Jó gyakorlat, ha egy függvény egyetlen célt szolgál, így könnyen újrahasználható.
  • Használj paramétereket: Így a függvény rugalmas lesz, és nem kell minden esetben új kódot írni.
  • Ne feledd a return-t: Ha a függvény valamilyen eredményt ad vissza, mindig használd a return-t.
  • Dokumentáld röviden: Hasznos lehet a függvény fölé rövid kommentet írni a működéséről.
  • Próbáld ki különböző bemenetekkel: Teszteld a függvényedet, hogy biztosan jól működjön minden esetre.
  • Ne másold a kódot többször: Használd a függvényt, így a programod rendezett és könnyen karbantartható lesz.
