1. Változók, Típusok és Adatbekérés

A Pythonban az input() függvény mindig sztringet (szöveget) ad vissza! Ha számokkal szeretnénk műveletet végezni, kötelező a típuskonverzió (int() vagy float()).

Kódminta:

nev = input("Hogy hívnak? ")                       # str (szöveg)
kor = int(input("Hány éves vagy? "))                # int (egész szám)
magassag = float(input("Hány méter magas vagy? ")) # float (tizedes szám)

# Sztring formázás f-string segítségével
print(f"Szia {nev}! Jövőre {kor + 1} éves leszel.")

2. Kiíratás és Számok Formázása (round vs :.2f)

Érettségin gyakori feladat az átlagok kerekítése 2 tizedesjegyre. Nem mindegy azonban, melyik módszert használjuk!

Kódminta:

atlag = 12.5

# 1. round() függvény (ha a végén 0 lenne, lecsapja)
print(round(atlag, 2))  # Kimenet: 12.5

# 2. Formázott sztring :.2f (FORSZÍROZZA a 2 tizedesjegyet!)
print(f"Egy alkalommal átlagosan {atlag:.2f} l üzemanyagot vásároltak.") # Kimenet: 12.50

🔍 Melyiket mikor használjuk?

A {atlag:.2f} formátumot akkor használd, ha a feladat szövege kifejezetten kéri, hogy mindig látszódjon a két tizedesjegy (például pénzösszegeknél vagy kiíratási mintáknál, ahol a 12.50 elvárás a 12.5 helyett).

3. Sztringek és Szeletelés (Slicing)

A szövegek karaktereit az indexük alapján érhetjük el (a számozás 0-tól kezdődik). A szeletelés (slicing) szintaxisa: szoveg[start:stop].

Kódminta (Benzinkutas / Kódos feladat példa):

kod = "B20"  # B = Benzin, 20 = Literek száma

tipus = kod[0]      # 'B'  -> Első karakter (0. index)
liter = kod[1:]     # '20' -> Az 1. index-től a legvégéig!

print(f"Típus: {tipus}, Mennyiség: {int(liter)} liter")

4. Listák, append(), len(), sum()

A lista összetett adatszerkezet. Dinamikusan bővíthető az append() metódussal, elemszáma a len(), összege pedig a sum() függvénnyel kérdezhető le.

Kódminta:

szamok = [12, 45, 8]

# 1. Elem hozzáadása
szamok.append(30)   # A lista tartalma: [12, 45, 8, 30]

# 2. Elemszám (Lista hossza)
db = len(szamok)    # 4

# 3. Elemek összege
osszeg = sum(szamok) # 95

print(f"Összesen {db} adat van, összegük: {osszeg}")

5. Ciklusok (for, range, while)

A) for ciklus és a range()

Akkor használjuk, ha tudjuk a lépések számát, vagy végig akarunk menni egy lista elemein.

# 1. Lista elemeinek bejárása
gyumolcsok = ["alma", "banán", "narancs"]
for gyumolcs in gyumolcsok:
    print(gyumolcs)

# 2. Ismétlés N-szer (1-től 5-ig)
for i in range(1, 6): # range(start, stop) -> a stop index már nincs benne!
    print(f"{i}. próbálkozás")

B) while ciklus (Feltételes leállás)

Akkor használjuk, ha nem tudjuk előre, hányszor kell lefutnia (pl. ENTER-re történő kilépésig).

adatok = []

while True:
    be = input("Adj meg egy adatot (ENTER = vége): ")
    if be == "": # Ha üres sztringet kapunk (csak ENTER-t nyomott)
        break   # Azonnal kilépünk a ciklusból
    adatok.append(be)

print(f"Beolvasva: {len(adatok)} db adat.")

6. Véletlenszámok (import random)

Véletlenszerű értékek generálásához az érettségin a randint() és a choice() a két legfontosabb függvény.

Kódminta:

import random

# 1. Véletlen egész szám 1 és 6 között (mindkét határ benne van!)
kocka = random.randint(1, 6)

# 2. Véletlen elem kiválasztása egy listából
nyeremenyek = ["Póló", "Sapka", "Karszalag"]
sorsolt = random.choice(nyeremenyek)

print(f"Dobás: {kocka}, Nyeremény: {sorsolt}")
