1. Adattábla létrehozása és Importálás

A feladatok mindig meglévő adatok importálásával (pl. .txt, .csv) vagy új tábla kézi létrehozásával kezdődnek.

A) Adatimportálás lépései:

  1. Külső adatok → Új adatforrás → Fájlból → Szövegfájl.
  2. Válaszd az Elválasztott opciót, majd állítsd be a határolójelet (leggyakrabban Tabulátor vagy Pontosvessző).
  3. Kiemelten fontos: Pipáld be az „Az első sor tartalmazza a mezőneveket” opciót!
  4. Állítsd be a mezők adattípusait (Szöveg, Szám, Dátum) és jelöld ki az elsődleges kulcsot.

B) Új tábla építése leírás alapján (Táblatervező):

  • Nyisd meg a Létrehozás → Táblatervező nézetet.
  • Adatmező tulajdonságai (alsó panel): Mezőméret (pl. szövegnél 50), Kötelező (Required = Igen/Nem), Alapértelmezett érték.
  • Összetett kulcs beállítása: Ha egy táblának két kulcsa van, tartsd nyomva a CTRL billentyűt, jelöld ki mindkét mezőt, és kattints a KULCS ikonra!

2. Általános Lekérdezési Szintaxis Kisokos

A) Névrészletek és Helyettesítő Karakterek (Like)

A Like (Hasonló) operátort akkor használjuk, ha szövegrészletekre keresünk rá.

  • Like "K*" → K betűvel kezdődő szavak (pl. Kovács, Kassa).
  • Like "*utca" → utca szóra végződő kifejezések (pl. Petőfi utca).
  • Like "*patak*" → A szövegben bárhol szerepel a "patak" szó (pl. Rákos-patak, Patakpart).
  • Like "T?ra" → A ? pontosan egy tetszőleges karaktert helyettesít (pl. Túra, Tára).

B) Hiányzó és Meglévő Adatok Szűrése (Is Null / Is Not Null)

⚠️ Örök szabály: Hiányzó mezőkre soha ne használj = "" vagy = Null kifejezést!
  • Is Null → Kiszűri azokat a rekordokat, ahol a mező üres / nincs kitöltve.
  • Is Not Null → Kiszűri azokat a rekordokat, ahol a mező ki van töltve.

C) Dátumok Használata és Dátumfüggvények

A konkrét dátumértékeket kötelező kettőskeresztek (#) közé zárni!

  • Pontos dátum: #2026/07/20# vagy #2026.07.20#
  • Intervallum: Between #2026/01/01# And #2026/12/31#
  • Beépített dátumfüggvények:
    • Now() → Pontos mai dátum ÉS idő.
    • Date() → Csak a mai dátum.
    • Year(dátum) → Kinyeri a dátumból az évszámot (pl. Year(Now()) az aktuális évet adja vissza).

D) Operátorok és Logikai Műveletek

  • Nem egyenlő: <> (pl. <> "Budapest")
  • És / Vagy kapcsolatok:
    • AND (ÉS): A lekérdező rácsban egy sorba írjuk a feltételeket.
    • OR (VAGY): A lekérdező rácsban külön sorokba (Vagy sor) írjuk őket.
  • Kötelező Zárójelezés: Ha az AND és OR műveleteket kevered, zárójelezned kell! 
    -- HELYES logikai zárójelezés:
Megye = "Zala" AND (Ár > 5000 OR Ár < 1000)

E) Számított Mezők és Átnevezés (AS)

SQL nézetben az átnevezés az AS kulcsszóval történik: SELECT [NettóÁr] * 1.27 AS BruttóÁr FROM Termékek;

F) Összegző / Csoportosító Lekérdezések

A vizsgafeladatok többségében nem egyenként kell kilistázni a rekordokat, hanem valamilyen szempont alapján csoportosítva kell kiszámolnod egy értéket.

💡 A kulcs a gondolkodásmódban van:
Keresd a feladat leírásában a „-ként / -onként” végződéseket!
„Városonként” → Város szerint csoportosítunk.
„Iskolánként” → Iskola szerint csoportosítunk.
„Megyénként” → Megye szerint csoportosítunk.

1. A leggyakoribb aggregáló függvények:

  • COUNT(mező) → Rekordok megszámlálása (pl. „Hány híd/diák van?”).
  • SUM(mező) → Értékek összeadása (pl. „Hidak teljes hossza”).
  • AVG(mező) → Átlagszámítás (pl. „Átlagos kor vagy pontszám”).
  • MIN(mező) / MAX(mező) → Legkisebb vagy legnagyobb érték.

2. Gyakorlati SQL Példák:

A) "Hány diák jár az egyes iskolákba?" (Iskolánkénti darabszám)

SELECT iskola, COUNT(diak_id) AS diakok_szama
FROM diakok
GROUP BY iskola;

B) "Mennyi az átlagos hídhossz városonként, de csak Zala megyében?" (Szűrés + Csoportosítás)

SELECT telepules_nev, AVG(hossz) AS atlagos_hossz
FROM hidak
WHERE megye = 'Zala'
GROUP BY telepules_nev;
🔥 Szűrési kisokos (WHERE vs. HAVING):
• WHERE: A csoportosítás ELŐTT szűr (egyedi rekordokra, pl. WHERE megye = 'Zala').
• HAVING: A csoportosítás UTÁN szűr az aggregált értékre (pl. HAVING COUNT(diak_id) > 5 → csak ahol 5-nél több diák van).

📝 Érettségi Mintafeladat (Hídleltár) – SQL Megoldások

A középszintű érettségi Hídleltár (2022. május) feladatsorának hivatalos és hibátlan SQL lekérdezései, magyarázatokkal.

2. Feladat (2duna)

Ábécérendben a Dunát átívelő hidak neve, hossza és átadási éve.

SELECT nev, hossz, atadas
FROM hid
WHERE athidalas = "Duna"
ORDER BY nev;

3. Feladat (3patak)

Hidak neve és áthidalása, ahol az áthidalás neve tartalmazza a „patak” szót.

SELECT nev, athidalas
FROM hid
WHERE athidalas LIKE "*patak*";

4. Feladat (4zala)

Zala megye egyes településeihez hány híd tartozik? (Település neve és a hidak száma).

SELECT telepules.nev, COUNT(hidaz) AS hidak_szama
FROM hid, kapcsolo, telepules
WHERE hid.az = kapcsolo.hidaz 
  AND kapcsolo.telepulesaz = telepules.az
  AND telepules.megye = "Zala"
GROUP BY telepules.nev;
💡 SQL Tipp: Az összekapcsolási feltételeket (WHERE hid.az = kapcsolo.hidaz...) kötelező megadni, különben az SQL mindent mindennel összeköt (DeCarte-szorzat), és hibás eredményt ad!

5. Feladat (5korok)

Budapesti hidak neve és életkora, az utóbbi szerint csökkenő sorrendben. Az aktuális évet függvénnyel határozd meg!

SELECT hid.nev, (YEAR(NOW()) - atadas) AS eletkor
FROM hid, kapcsolo, telepules
WHERE hid.az = kapcsolo.hidaz 
  AND kapcsolo.telepulesaz = telepules.az
  AND telepules.nev = "Budapest"
ORDER BY (YEAR(NOW()) - atadas) DESC;

Megjegyzés: Az AS eletkor segítségével az oszlop az érettségin szép, értelmezhető nevet kap a névtelen számított mező helyett.

6. Feladat (6pentele)

Azoknak a hidaknak a neve és hossza, amelyek a „Pentele” névrészletet tartalmazó hídnál hosszabbak.

SELECT nev, hossz
FROM hid
WHERE hossz > (
    SELECT MAX(hossz) 
    FROM hid 
    WHERE nev LIKE "*Pentele*"
);
